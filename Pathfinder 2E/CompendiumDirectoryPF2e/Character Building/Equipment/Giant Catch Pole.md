# Giant Catch Pole
## Item 3
### [uncommon](uncommon "Uncommon Rarity Trait")


**Price** 50 gp; 
**Bulk** 2; **Size** med
**Usage** held-in-two-hands

A giant catch pole is made from thicker steel and heavier rope. It functions the same as a catch pole but can be used to [[Actions/Grapple|Grapple]] creatures up to your normal size limit. However, the implement is so ungainly that you are [[Conditions/Clumsy 1|Clumsy 1]] while wielding it.

*Source: Pathfinder Howl of the Wild*
